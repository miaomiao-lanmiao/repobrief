# RepoBrief v0.1.2

Maintenance release draft, 2026-11-09 (Asia/Shanghai).

Breaking-change footers previously kept only their first line. Migration steps
on following lines or in later paragraphs disappeared from changelog/PR reports.
This update retains those instructions until the next Conventional Commit footer
and keeps separate breaking-change entries separate. Both `Token: value` and
`Token #value` footer boundaries are recognized.

Whitespace is normalized for safe display, including Unicode line and paragraph
separators and carriage returns inside footer values. Existing CLI flags, exit
codes and JSON schema remain unchanged. No new runtime dependencies or network calls.

Three new unit regressions and a real-Git CLI assertion reproduced the omission
before the repair. The 57 local tests include a compatibility check for embedded
separators. The full local gates are recorded in `docs/verification-0.1.2.md`.
Six hosted CI jobs are required before this draft.

Download `repobrief-cli-0.1.2.tgz`, then install with:

```sh
npm install --global ./repobrief-cli-0.1.2.tgz --ignore-scripts
```

Requires Node.js 22+ and Git. No npm registry publication is performed.
