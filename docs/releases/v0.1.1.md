# RepoBrief v0.1.1

Maintenance release draft, 2026-10-23 (Asia/Shanghai).

- Honor explicit repository paths when the calling terminal sets Git repository
  selector variables. Linked worktrees continue to resolve their own metadata.
- Preserve legal trailing spaces in repository paths on platforms that support them.
- Update pinned checkout/setup-node Actions, avoid duplicate feature-branch CI
  runs, and keep Node.js type definitions aligned with the supported Node 22 floor.
- Make the package verification gate compare the built CLI version with package
  metadata so future patch releases do not require a hardcoded test version.

53 local tests, strict TypeScript build, security checks and offline package
installation passed. Hosted six-job CI is required before creating this draft.
JSON schema and existing command options remain compatible.

Download `repobrief-cli-0.1.1.tgz` and install with:

```sh
npm install --global ./repobrief-cli-0.1.1.tgz --ignore-scripts
```

Requires Node.js 22+ and Git. No npm registry publication is performed.
