# RepoBrief v0.1.0

Initial release draft.

## Included

- Local Git changelogs with Conventional Commit grouping, breaking-change notes,
  revision ranges, Markdown and JSON.
- Offline npm dependency configuration checks with actionable findings and
  optional CI thresholds; no vulnerability or malware verdicts.
- Merge-base PR descriptions containing commits, changed files and a human
  verification checklist.

## Installation from the release asset

Download the attached `repobrief-cli-0.1.0.tgz`, then run:

```sh
npm install --global ./repobrief-cli-0.1.0.tgz --ignore-scripts
repobrief --help
```

Requires Node.js 22+ and Git. The npm tarball contains built JavaScript and has no
runtime dependencies. It is not an npm registry publication.

## Checks

Unit and real-repository smoke tests, TypeScript build, static security checks,
and an offline installation of the packed CLI are required. The publishing
script verifies GitHub CI at the tagged HEAD before creating this draft.

## Limits

Only root npm manifests and lockfiles v2/v3 are supported. No network calls or
package-script execution occur during analysis. Findings require human review.
